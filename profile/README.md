# AnyRail

> One named AnyRail plan. Finish the turnout. Leave a note the next person can read.

## Session Card

| Slice | What you do in AnyRail | What remains |
|-------|------------------------|--------------|
| Arrival | Open AnyRail and name today's model railroad | A titled track plan |
| Focus | Keep only live turnouts on the AnyRail board | A short geometry list |

## How AnyRail Sits

AnyRail does not replace the benchwork, the cork, or the track boxes you already own. It sits beside them as a named model railroad desk for one job: which track plan is live, which turnout library still matches the lengths, and what the next person should read before wood is cut.

If two people share a layout PC, each keeps an AnyRail style of their own. Extra rooms wait for their own title instead of crowding the live plan.

## Traffic Light

| Signal | On the AnyRail board | What you do |
|--------|----------------------|-------------|
| Green | Named plan, short live turnout list | Continue the same geometry |
| Amber | Two rooms mixed in one track plan | Split the set before you cut |
| Red | No title, no note, lengths unlabeled | Stop and name the plan first |
| Clear | Handoff written, live turnouts few | Close AnyRail and leave the desk |

## Open Order

1. Open the last AnyRail track plan, not a new empty model railroad.
2. Read the turnout list and the last handoff.
3. Finish one visible length inside AnyRail.
4. Write what changed, then close with fewer unlabeled turnouts than you found.
5. If the set feels crowded, drop anything that belongs to a different AnyRail room.

## Desk Fit

| Who | What AnyRail holds |
|-----|--------------------|
| Layout desk | Track plan and turnout library for a railroad you own |
| Shared desk | One AnyRail profile per person |
| Club room | Named geometry waiting for the next build |

## After a Week

A week in AnyRail is not a larger unlabeled wood pile. It is the same title, a shorter live turnout list, and a note that still makes sense before the next cut. Take finished lengths off the live set so the next visit starts on the plan that is still open.

## Sign-off

- [ ] The AnyRail workspace name is short enough to scan
- [ ] Only the live track plan is on the board
- [ ] A second person can read the handoff
- [ ] Finished rooms are off the live AnyRail set

## Field Note

AnyRail is easier to trust when the model railroad stays smaller than the scrap bin it came from. Name the plan, keep the live geometry, finish one visible turnout, and write what changed.
